D.A.R.E. THAILAND — Dashboard Update

สิ่งที่ปรับปรุง
- ใช้โลโก้ D.A.R.E. THAILAND บนริบบิ้นธงไทยที่ผู้ใช้ส่งมา
- ใช้ภาพมาสคอตครูช้างสีม่วงที่ผู้ใช้ส่งมาใน Sidebar
- ปรับ Hero ให้ภาพครูช้างและนักเรียนเด่นขึ้น พร้อมรักษาความอ่านง่ายของข้อความ
- เพิ่มแผงสถานภาพครูตำรวจ D.A.R.E. จากไฟล์ Excel ที่แนบ (สรุป 30 ก.ย. 2569)
- เพิ่มกราฟระดับเข็มและจำนวนครูแยกตามหน่วย พร้อมค้นหา กรอง และแสดงทุกหน่วย
- เพิ่มแอนิเมชันเข้าองค์ประกอบและรองรับ prefers-reduced-motion
- ปรับ esbuild ใน package.json เป็น ^0.28.0 ให้ตรงกับ peer requirement ที่พบใน Vite 8

หมายเหตุ
- จำนวนครูและหน่วยในแผงสถานภาพมาจากชีต "แยกหน่วย"
- การจัดกลุ่มระดับเข็มเป็นการสรุปเบื้องต้นจากชีต "แบบใหม่" ควรตรวจทานก่อนใช้เป็นรายงานทางการ
- Build ไม่สามารถยืนยันได้ในสภาพแวดล้อมนี้ เนื่องจาก npm install ใช้เวลานานเกินกำหนด


ปรับปรุง Dashboard รอบแก้ไขหน้าตา:
- ลดความขาวทับภาพ Hero เพื่อให้เห็นภาพครูช้างและนักเรียนชัดขึ้น
- ขยายหัวข้อ Hero บนหน้าจอขนาดใหญ่และเพิ่มความสูงของพื้นที่ Hero
- ย้ายโมดูลสถานภาพครูตำรวจ D.A.R.E. ไปไว้หลังส่วนกิจกรรมและสื่อ เพื่อให้หน้าแรกอ่านง่ายและไม่แน่นเกินไป
- ลดเงาและปรับระยะห่างของโมดูลสถานภาพให้ดูเบาขึ้น


อัปเดต Dashboard รอบใหม่:
- จัดพื้นที่เนื้อหาให้อยู่ในความกว้างเหมาะสม พร้อมระยะขอบที่อ่านง่าย
- ปรับ Hero ให้เด่นและอ่านหัวข้อได้ชัดขึ้น
- เรียงลำดับกิจกรรมล่าสุดและสื่อการเรียนรู้ก่อนโมดูลสถานภาพครู D.A.R.E.
- ย้ายโมดูลสถานภาพครูลงหลังแผนที่ สถิติ และปฏิทิน เพื่อให้หน้าหลักใกล้เคียงภาพอ้างอิง
- ปรับ esbuild เป็น ^0.28.0 ให้ตรงกับข้อกำหนด Vite 8 ที่แจ้งไว้ก่อนหน้า


อัปเดตทะเบียนกำลังพลและสถานศึกษา (15 ต.ค. 2569)
- นำเข้ารายชื่อครูตำรวจ D.A.R.E. จำนวน 250 ราย จากชีต "แบบใหม่"
- นำเข้ารายชื่อสถานศึกษาที่พบในบัญชี 354 รายการ จากข้อมูลโรงเรียนที่ครูแต่ละคนรับผิดชอบ
- เพิ่มข้อมูลประกอบในทะเบียนครู เช่น ตำแหน่ง โรงเรียนที่สอน จำนวนนักเรียน ปีเกษียณ ชั่วโมงรวม และระดับเข็ม
- ปรับการเริ่มต้นข้อมูลให้โหลดทะเบียนจากไฟล์ชุดใหม่ แม้เบราว์เซอร์จะมีข้อมูลตัวอย่างเก่าอยู่แล้ว โดยยังเก็บรายการที่ผู้ใช้เพิ่มเอง
- ต้นทางข้อมูลแนบไว้ใน docs/สถานภาพครูตำรวจ D.A.R.E 30 ก.ย.69.xlsx
หมายเหตุ: ข้อมูลจังหวัด/อำเภอ/ตำบลและจำนวนนักเรียนรายสถานศึกษาที่ไม่มีในต้นทางจะเว้นว่างหรือเป็น 0 ไม่สร้างข้อมูลขึ้นเอง
